# 팀 지식볼트 (brain-vault) 활용

brain-vault MCP 서버가 연결되어 있다. 팀 지식볼트(team-brain)를 서버가 대신 읽어주는 읽기 전용 창구이며, 데이터는 항상 조회 시점의 최신 상태다.

## 도구

- `search_vault { query, max_results? }`: 볼트 전체(공유 + 본인 personal) 키워드 검색. 여러 단어는 AND.
- `read_note { path }`: 문서 전문 읽기. 검색 결과의 상대경로 또는 위키 페이지 id를 넘긴다.
- `list_recent { limit? }`: 최근 수정된 문서 목록. 팀의 최근 흐름 파악용.
- `save_memo { content, scope? }`: 작업 기록·메모를 볼트 인박스(raw/memos)에 저장. 유일한 쓰기 도구.

## 언제 쓰나

- 회사·팀·프로젝트·과거 결정에 관한 질문이면 **답하기 전에 볼트부터 검색**한다. 일반 지식으로 추측하지 않는다.
- "요즘 팀에서 무슨 일 있었어" 류는 `list_recent`부터.
- 볼트에 뭐가 있는지 감이 없으면 `read_note`로 `shared/wiki/index.md`(전체 목차)를 먼저 읽는다.

## 작업 중 선제 활용 (묻지 않아도)

- 명시적인 팀 질문이 없어도, 지금 하는 작업의 주제를 팀이 과거에 다뤘을 법하면(배포·터널·서버 설정, 팀이 쓰는 도구, 전에 겪었을 만한 에러, 관련 프로젝트) 본격적으로 진행하기 전에 `search_vault`로 한 번 확인한다.
- 가볍게 한다: 검색 한두 번이면 충분하다. 관련 기록이 없으면 조용히 넘어가고 작업을 계속한다. 매 턴 반복하지 않는다.
- 기록을 찾으면 "볼트에 관련 기록이 있다"고 출처와 함께 알리고 작업에 반영한다. 볼트 기록이 현재 상황과 다르면(옛 구성 등) 그 차이도 짚는다.

## 볼트 구조 (사전지식)

카파시 LLM Wiki 패턴. 사람이 원본을 모으고, AI 사서가 위키를 유지한다.

```
shared/                  팀 공유
├─ wiki/                 지식 페이지 (index.md = 목차, overview.md = 큰 그림, log.md = 작업 로그)
│  ├─ entities/          사람·회사·도구·제품·프로젝트
│  ├─ concepts/          아이디어·패턴·기법
│  ├─ sources/           인제스트한 소스별 요약
│  └─ synthesis/         질의 답변을 저장한 종합
├─ raw/                  불변 원본 (memos/ clippings/ files/)
├─ journal/              운영 큐 (인터뷰 질문 등)
└─ calendar/             팀 일정
personal/<이름>/          개인 공간 (같은 구조. 서버가 본인 것만 보여준다)
```

## 작업 기록 보내기 (save_memo)

- 의미 있는 작업 단위가 끝났을 때(기능 구현, 까다로운 문제 해결, 중요한 결정, 새로 배운 것) 또는 사용자가 "brain에 보내줘", "작업 기록해줘"라고 할 때 사용한다.
- **사용자가 저장을 요청했으면 초안을 보여주며 확인받지 말고 바로 저장한다.** 내용을 짧은 마크다운(`# 제목` + 무엇을, 왜, 어떻게, 배운 점)으로 정리해 곧장 save_memo를 호출하고, 저장 후 제목 한 줄로만 보고한다. 초안을 미리 출력해 승인을 구하는 절차는 없다 — 인박스는 나중에 앱에서 소화·수정·폐기할 수 있는 임시 보관함이라 되돌리기 쉽다.
- 사용자가 요청하지 않았는데 기록할 가치가 커 보일 때만 "brain 인박스에 기록해둘까요?"라고 제안한다. 거절하면 조용히 넘어간다.
- 저장 범위(개인/공유)가 애매할 때만 한 줄로 묻는다. 내용 자체를 승인받지는 않는다.
- 기본은 개인 인박스. 사용자가 팀 공유를 원할 때만 `scope: "shared"`.
- 저장해도 바로 노트가 되지 않는다. brain-chat 앱의 인박스에 쌓이고, 사용자가 앱에서 "노트로 소화"를 누르면 사서가 위키에 반영한다. 저장 후 이 흐름을 한 줄로 안내한다.

## 사용 규칙

- 볼트 내용을 인용할 때는 출처 경로를 함께 말한다 (예: shared/wiki/concepts/foo.md).
- 쓰기는 save_memo(인박스에 새 메모 추가)뿐이다. 위키 페이지·기존 문서 수정은 이 창구로 할 수 없고, brain-chat 앱(https://brain.inspirit-dev.cloud)에서 한다.
- 다른 사람의 personal/은 서버가 차단한다. 접근 거부 응답이 오면 그대로 받아들이고 우회하지 않는다.
- 검색이 비면 단어를 줄이거나 동의어로 재시도하고, 그래도 없으면 "볼트에 기록 없음"을 명시한다.
